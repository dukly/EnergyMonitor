# ⚡ ЭнергоМонитор  
Мониторинг инвертера через Modbus TCP (через USR‑W610)

**ЭнергоМонитор** — это лёгкая и надёжная Python‑утилита для опроса инвертера по протоколу Modbus TCP.  
Проект поддерживает работу через Wi‑Fi/RS485‑конвертер **USR‑W610**, собирает телеметрию, логирует ошибки и сохраняет данные в удобном текстовом формате.

---

## 🚀 Возможности

- Чтение регистров инвертера (float32 и int16)
- Поддержка Modbus TCP через USR‑W610
- Логирование ошибок в `error_log.txt`
- Запись телеметрии в `log.txt`
- Расшифровка статусов и кодов ошибок
- Обработка исключений и защита от обрывов связи

| Код ошибки              | 32019 | int   |

## 🧩 Интеграция с USR‑W610

1. Подключите инвертер к RS485‑клеммам устройства  
2. Настройте USR‑W610 в режиме **TCP Server**  
3. Укажите порт (например, 502)  
4. Настройте RS485 (9600 8N1 или параметры вашего инвертера)  
5. Установите статический IP, например `192.168.0.100`

После этого ЭнергоМонитор сможет подключаться к устройству как к обычному Modbus TCP серверу.

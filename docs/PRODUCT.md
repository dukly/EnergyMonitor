# САНХОРС Мониторинг — продукт и тарифы

**Бренд:** САНХОРС ([sunhors.ru](https://sunhors.ru/))  
**Продукт:** **САНХОРС Мониторинг** (B2B: **SUNHORS Energy Cloud**)  
**Компонент на объекте:** **sunhors-agent** (edge-агент, этот репозиторий)

## Ценность

- Прозрачная выработка СЭС после монтажа «под ключ»
- Ранние алерты при простое инвертора
- Единый сервис: монтаж и цифровое сопровождение от САНХОРС

## Тарифная сетка

| Тариф | Аудитория | Edge (агент) | Облако | Монетизация |
|-------|-----------|--------------|--------|-------------|
| **Старт** | Дом, малый объект | Локальные логи + SQLite 30 дней | Нет | Включено в сервис 1 год |
| **Бизнес** | СЭС 30–300 кВт | Агент + синхронизация | Дашборд, алерты, история 2 года | Подписка / объект / мес |
| **Про** | Несколько площадок | Multi-site | SLA, ESG-отчёты, API | Договор + площадка |
| **Партнёр** | Интеграторы | White-label | Реселлерская панель | % с оборота |

## MVP личного кабинета (portal)

Реализация: [`portal/`](../portal/)

| Экран | Функции MVP |
|-------|-------------|
| Дашборд объекта | Текущая мощность AC, статус, ошибка, энергия за день |
| История | График мощности за 24 ч / 7 дней |
| Уведомления | Список последних алертов (заглушка в MVP) |
| Подписка | Тариф, срок действия лицензии, `site_id` |

## Технические идентификаторы

- `SITE_ID` — объект клиента
- `LICENSE_KEY` — ключ подписки (проверка на `license API`)
- `INVERTER_PROFILE` — `deye`, `goodwe`, `default`
